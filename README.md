# 👟 Dashboard de Vendas - Nike

Este projeto consiste numa análise exploratória e na construção de um dashboard interativo para monitorizar as vendas de produtos da **Nike**, permitindo filtrar resultados por região e categoria de produto.

---

## 📊 Funcionalidades do Dashboard

- **Indicadores de Desempenho (KPIs):** Faturamento Total, Unidades Vendidas e Ticket Médio por Pedido.
- **Gráfico de Barras Interativo:** Faturamento por modelo de produto (Nike Air Max, Dunk Low, Air Force 1, etc.).
- **Gráfico de Rosca:** Distribuição percentual do faturamento pelas regiões.
- **Filtros Dinâmicos:** Filtragem lateral por Região e Categoria (Calçado e Vestuário).
- **Tabela de Dados:** Exibição detalhada dos pedidos com suporte a ordenação.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.11+
- **Análise de Dados:** Pandas, NumPy
- **Visualização de Dados:** Plotly Express
- **Dashboard Web:** Streamlit
- **Controlo de Versão:** Git & GitHub
